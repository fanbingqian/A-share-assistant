2026-11-21 · 从 AI-Hel2 移植力导向图谱渲染层（零依赖）
本次只改造图谱的渲染与交互，数据契约（data/knowledge/graph.json）、笔记列表、入库与抽取逻辑全部未动。笔记照常记录 →「整理为图谱」后，新渲染器自动生效。

改了什么

  • 新增web/v2/graph-engine.js：从 AI-Hel2 逐行移植的物理引擎（Barnes-Hut 四叉树斥力 + Hooke 弹簧 + 圆碰撞 + 自动冻结）与数据适配层（度数统计、类型着色、同向边合并）。纯原生 JS，零依赖。
  • 重写web/v2/v2.js 的 loadGraph()：静态放射布局 → 力导向 SVG 渲染 + 完整交互。
  • 增强web/v2/index.html / v2.css：图谱工具条、图例、节点详情、参数面板。
