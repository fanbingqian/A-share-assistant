研究看板 原有 · 已上线

现有 21 模块的研究产出。这些是智能体增量事实账本（factLedger）的真实输入——复盘里每条论断都要能回查到这里。

周期事件 /api/cycle

21 条制度性规律事件 + 人工日历；三段 CAR（预期 [T-20,T-1] / 兑现 [T-1,T+1] / 衰减 [T+1,T+20]）；影视暑期档 / 国庆档规则，春节档农历不推算。

四形态：利好出货 / 趋势延续 / 后知后觉 / 利空出尽。板块阶段性提前告知 n≥5 才给。

资金主体 /api/flow

245 个交易日龙虎榜按日×席位幂等回填；机构专用 / 沪深股通 / 拉萨系 / 高频活跃席位画像；两融月度抽样 + 当前按日聚合；微/小/中/大盘资金倾向。

排除「自然人 / 中小投资者」投资者结构披露行污染；单边与震荡行情分开统计。

避险四级 /api/riskoff

L1 板块内轮动 / L2 风格避险 / L3 离场 / L4 离境，七项证据链。明确回答「钱去了其他板块还是出了股市」。

当前示例：L2 + L1 —— 钱没走，场内搬家（银行 +2.90% vs 微盘 −7.65%）。

预期研究层 edge /api/edge/*

496 个行业板块相对强弱 / 8 条主线 / 拥挤度；重组·回购·并购市值重估条件齐备度；板块价格周期阶段；10 维多因素叠加指纹。
